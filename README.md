# TriagePilot

TriagePilot is a Rovo agent for Jira backlog triage, built on Atlassian Forge for the Codegeist 2026 hackathon by Endra Teguh Setyawan, an individual developer based in Indonesia. It reads Jira issues and Confluence pages inside your own Atlassian site to suggest duplicates, score urgency, and draft comments and labels — and it only applies changes after a human confirms them.
