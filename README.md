# TriagePilot

TriagePilot is a Rovo agent for Jira backlog triage, built on Atlassian Forge for the Codegeist 2026 hackathon by PT. Enamika Branding Solution. It reads Jira issues and Confluence pages inside your own Atlassian site to suggest duplicates, score urgency, and draft comments and labels — and it only applies changes after a human confirms them.
